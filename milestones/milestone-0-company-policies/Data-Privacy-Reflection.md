# Onboarding Task - Data Privacy & Confidentiality

## Research Questions

### What types of data are considered confidential at Focus Bear?

- **Identification Data -** Personal data used to contact, identify, or register a natural person.
- **Social Data -** Personal data related to personal characteristics and lifestyle.
- **Academic & Professional Data -** Personal data related to academic levels, training, career and working experience.
- **Commercial and Marketing Data -** Personal data related to preferences in Marketing, Activities and Businesses.
- **Technical Data -** Personal data related to technology used to access websites, applications, software, and platforms.
- **Economic, Financial and Insurance Data -** Personal data related to the financial situation and banking details.
- **Profile Data -** Personal data related to purchases, service preferences, feedback and surveys.
- **Aggregate Data -** Personal data related to statistical or demographic information (e.g. Cookies).
- **Special Category of Personal Data -** Religious beliefs and personal data related to health.

### What are best practices for handling confidential data?

- Always **encrypt data**, whether at rest or in transit.
- For all accounts, **use strong and unique passwords** and **enable multi-factor authentication.**
- **Avoid storing sensitive information in unsecure locations** like public cloud storage.
- Access to data should only be given to those with **permission and those who need it.**
- Only use **allowed channels and verify recipients** when sharing information.
- Keep development environment **secure by ensuring secrets or API keys are not committed to version control**

### How should you respond to a suspected data breach or accidental disclosure of confidential information?

- **Immediately report** any suspicious activity in the system
- **Disconnect affected systems** from the network, and revoke compromised credentials to prevent further unauthorized access.
- **Assess the situation** by gathering details such as type of data involved, time occurred, and the like for further review

### How should you store, share, and dispose of sensitive information safely?

- **Storing:** use approved or organization-sanctioned cloud services, ensure full-disk encryption is enabled and hardware-encrypted USB drivers are used when needed.
- **Sharing:** only share information with authorized recipients through a secured network.
- **Disposing:** deletion of data and information should only be done according to GDPR and company policies.

### What are some common mistakes that lead to data privacy issues, and how can they be avoided?

| Data Privacy Mistakes                    | Prevention                                                                                                  |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Oversharing on social media              | Avoid sharing real-time details, or plans. Adjust privacy settings to limit audience                        |
| Using weak or repeated passwords         | Ensure strong and unique passwords for all accounts                                                         |
| Skipping two-factor authentication (2FA) | Enable multi-factor authentication on all accounts for added security                                       |
| Clicking on suspicious links             | Never click on suspicious links, or fall for suspicious claims specially from unlisted or untrusted sources |
| Downloading apps from untrusted sources  | Only download apps from official stores. Review access and permissions to only allow necessary ones         |
| Ignoring software updates                | Keep devices and software updated to patch security vulnerabilities                                         |
| Using public Wi-Fi without protection    | When in public, avoid accessing sensitive information. Use VPN if necessary                                 |
