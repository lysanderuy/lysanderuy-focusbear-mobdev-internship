# Onboarding Task - Roles in an Agile Team

## Research Questions

### What are the key roles in an Agile team, and what does each role do

- **Developers -** They build and maintain the product, adding features and fixing bugs
  that come up along the way.
- **QA (Quality Assurance) -** Ensures product quality by testing features and looking for bugs.
- **Product Manager (PM) -** Defines priorities, user stories, and product vision.
- **Agile Project Manager (Agile PM) -** Leads the team by facilitating Agile practices, removing blockers and
  also keeps everything in place.
- **Other supporting roles (e.g., stakeholders, UX, customer support) -** Stakeholders, UI/UX designers, and
  customer support also provide feedback, design input, and other insights.

### How do these roles collaborate in Kanban vs. Scrum

| Role                  | Scrum                                                                                 | Kanban                                                                                                      |
| --------------------- | ------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Developers            | Work in sprints, complete committed stories, and attend daily stand-ups               | Continuously pull tasks, focus on smooth flow, and collaborate as needed                                    |
| QA                    | During sprints, they test and validate features, and attend reviews                   | Test tasks or features as they appear, usually working in parallel with developers                          |
| Product Manager       | Prioritizes backlogs, and clarifies requirements during planning                      | Continuously refining backlog and prioritizing work for smooth flow                                         |
| Agile Project Manager | facilitating Agile practices, removing blockers and also keeps everything in place.   | Maintain Kanban board, set WIP limits, improve workflow efficiency, and make sure everything is up to date. |
| Supporting Roles      | Attend regular meetings, engage in planning, reviewing or other important discussions | Provide feedback and input continuously, trigger new work items as needed                                   |

## Reflection

### What is your role, and how does it contribute to the Agile process

My role is a Developer, specifically for the Mobile Application as an intern. My main task as a developer is to
contribute to both frontend and backend needs of the mobile product. I attend stand-ups, planning, and reviews.
I take on specific tasks and work on different features for the application.

### How do your responsibilities overlap or interact with other roles in the team

I rely on the Product Manager for clear requirements and priorities for the features I develop while communicating
blockers or dependencies to the Project Manager. I work closely the UI/UX designers to implement user friendly
interfaces and discuss technical input on designs and with QA to make sure that all implemented features
are up to quality standards.
