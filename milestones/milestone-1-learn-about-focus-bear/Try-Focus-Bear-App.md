## Suggestions

- Make app pages more intuitive and easy to navigate.
- Allow users to change the app theme while maintaining design considerations for ADHD and AUDHD users.
- Make the layout and styling of the Stats page consistent with the rest of the application.
- Use a hamburger dropdown or another compact method for Stats tabs instead of occupying half the screen, so more
  space is available for main content.
- Allow users to add subtasks directly on the task creation page, so they don’t have to submit first and edit later.
