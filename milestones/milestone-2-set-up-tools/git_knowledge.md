## Reflections

### Have you used Git before? If so, in what context?

Yes, I’m very familiar with Git commands. I’ve used Git for full-stack web development projects, both collaborative
and personal, and to track academic projects as well as side hobbies like robotics.

### Which Git client (if any) did you choose? Why?

I chose VS Code as my Git client because it integrates Git functionality directly into the editor, making it easier
to commit, branch, and review project history without leaving the workspace.

### What was the most interesting thing you learned about Git today?

I learned that Git is a powerful version control system that lets you track changes, experiment safely with branches,
and collaborate efficiently on projects of any size. One very useful command I learned is **`git reflog`**, which lets
you view the history of all actions in your repository and recover commits that might otherwise seem lost.
