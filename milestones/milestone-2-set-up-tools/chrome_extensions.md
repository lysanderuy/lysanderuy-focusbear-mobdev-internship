## Research & Documentation

### Which extensions did you install? Why

I installed **React Developer Tools** to check and debug components, **Redux DevTools** to follow state changes,
**JSON Viewer** to read API responses clearly, and **Lighthouse** to see how the app performs. I picked these because
they make development faster and easier to understand.

### What was the most useful thing you learned

The most useful thing I noticed is how **React Developer Tools** lets you explore the component tree and props, which
makes understanding how the app is structured much easier. I also saw that **Lighthouse** gives clear feedback on
performance, accessibility, and best practices, which is helpful for spotting potential issues early and seeing where
improvements can be made.
