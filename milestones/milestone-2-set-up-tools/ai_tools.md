## Reflection

### Which AI tools did you try?

I first tried to experiment with GitHub Copilot to review code errors and it worked quite well. I also tried feeding
the same error to ChatGPT and Claude and both gave the same results.

### What worked well? What didn’t?

Honestly, all three worked quite well. However, I personally like to use ChatGPT and GitHub Copilot as my primary
tool for coding when I need assistance.

### When do you think AI is most useful for coding?

AI is most useful for debugging, where you can feed it error logs to narrow down cause much quicker. It is also useful
for reading and explaining long and complex documentations. AI also helps with exploring other solutions and ideas
during roadblocks.
