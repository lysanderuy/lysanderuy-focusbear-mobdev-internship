# Focus Bear Mobile Dev Internship - Onboarding

This repository contains onboarding deliverables for the Focus Bear Mobile Development internship, organized by milestone.

## Repository Structure

```plaintext
milestones/
├─ milestone-0-company-policies/
├─ milestone-0-working-in-an-agile-team/
├─ milestone-1-learn-about-focus-bear/
├─ milestone-2-set-up-tools/
├─ milestone-3-learn-git/
├─ milestone-4-clean-code/
├─ milestone-5-react-fundamentals/
├─ milestone-7-redux/
├─ milestone-8-react-native-fundamentals/
├─ milestone-10-interactive-performant-apps/
├─ milestone-11-debugging/
```

Each milestone folder includes task notes, reflections, and project work related to onboarding issues.

## Local Quality Checks

From the repository root:

```bash
npm run lint
npm run lint:md
```

The repository also runs CI checks for ESLint, Markdown linting, and spell checking on pull requests.

## Workflow

1. Create a milestone or feature branch (for example, `milestone/5-react-fundamentals`).
2. Complete the assigned issue tasks in the corresponding `milestones/` folder.
3. Commit with clear, scoped commit messages.
4. Push the branch and open a pull request linked to the issue.
5. Address feedback, then merge.
